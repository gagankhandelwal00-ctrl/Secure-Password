# 🔐 Secure Password Generator

A beginner-friendly Python project that generates a personalized password using the user's name, nickname, and birth year.

The program combines string slicing and string reversing techniques to create a password automatically.

## ✨ Features

- Takes the user's name as input.
- Takes the user's nickname as input.
- Takes the user's birth year as input.
- Extracts specific characters using string slicing.
- Reverses the birth year.
- Combines all inputs to generate a password.

## 🛠️ Technologies Used

- Python 3
- String Manipulation
- String Slicing
- String Reversing
- User Input (`input()`)
- Formatted Strings (f-strings)

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Run the Python file:
   ```bash
   python secure_password.py
   ```
4. Enter your name, nickname, and birth year.
5. Your generated password will appear on the screen.

## 💻 Example Output

```text
Enter your name: Gagan
Enter your nickname: Gagank
Enter your birth year: 2005

Your secure password is: Gagaga5002
```

## 🎯 Project Objective

The objective of this project is to practice Python string manipulation, slicing, reversing, and user input while building a simple personalized password generator.
